朝のブリーフィングを生成する。Cowork（Web版・スマホ）から呼ばれる前提で、ローカルファイル参照は使わずMCPだけで完結させる。

## 動作

以下を**並列で**取得し、1つのブリーフィングにまとめてまりこさんに提示する。1ソース失敗しても他は続行。

### STEP 1: データ取得（並列）

| ソース | ツール | 取得内容 |
|---|---|---|
| Google Calendar | `mcp__claude_ai_Google_Calendar__list_events` | 今日（JST 0:00-23:59）の予定。明日朝イチ予定も1件 |
| Notion 昨日の日報 | `mcp__mariko-notion__API-post-search` | クエリ: `{昨日YYYY-MM-DD}_Claude日報`。ヒットしたら `API-get-block-children` で本文取得 |
| Notion 作業インボックス | `mcp__mariko-notion__API-retrieve-a-page` + `API-get-block-children` | ページID: `3302b9e4cb4c81a89f01de0c87ec3538` |

### STEP 2: 出力（速報フォーマット）

```
☀️ {YYYY-MM-DD（曜）} おはようございます

📅 今日の予定（N件）
  HH:MM-HH:MM イベント名（場所/ツール）
  HH:MM-HH:MM イベント名
  （明日朝イチ: HH:MM イベント名）

📓 昨日のセッション
  ・やったこと要約（最大3点）
  → 未完了/申し送り: ○○○

📌 持ち越し（インボックスから）
  ・タスク内容（最大3点）

🎯 今日の最優先（3つまで）
  1. ○○○（理由: MTGまでに必要 / 昨日の続き / フォローアップ等）
  2. ○○○
  3. ○○○
```

## 取得ロジック詳細

### 昨日の日付（JST）
今日のJST日付から1日引く。週明け月曜の場合は金曜日を「昨日」として扱う（土日にセッションが無い前提）。土日も日報があればそれを使う。

### Calendar取得
- `list_events`: `time_min={今日のJST 00:00 ISO8601}`, `time_max={今日のJST 23:59 ISO8601}`
- 辞退・キャンセル除外
- 明日朝イチは別途取得: `time_min={明日 00:00}`, `time_max={明日 12:00}`, `max_results=1`

### Notion日報検索
1. `API-post-search` で `query="{昨日YYYY-MM-DD}_Claude日報"`
2. 上位ヒットの page_id を取得
3. `API-get-block-children` で本文ブロック取得
4. heading_2「🤖 本日の統合まとめ」配下の paragraph/bullet を抽出
5. 統合まとめが無ければ、子ページ（セッションN）の本文を要約

### 作業インボックス取得
- ページID `3302b9e4cb4c81a89f01de0c87ec3538` 直下の bulleted_list_item / to_do / paragraph を取得
- 上位3件まで表示（先頭優先＝直近追加分）

### 最優先タスク判定
以下の重み付けで3つに絞る:
1. **時間制約**: 今日のMTGの準備 > 今日期限のタスク
2. **継続性**: 昨日の未完了 > 新規
3. **クライアント優先**: クライアント案件 > 自社作業

## エラーハンドリング

- **MCP認証切れ**: そのソースをスキップし「[Calendar: 認証切れ]」と1行表示
- **Notion検索0件**: 「昨日の日報なし（休日 or 記録漏れ）」と表示し、続行
- **全ソース失敗**: 日付・曜日のみ出して「データソース接続を確認してください」と表示
- **「使えません」とすぐ報告しない**: 別MCPやフォールバック（claude_ai_Notion 等）を試してから報告する

## 注意

- **出力は簡潔に**。スマホ画面1〜2スクロールで読み切れる長さに収める
- **判断は提案、指示ではない**。「今日の最優先」はあくまで候補
- **メール本文・金額・個人情報は出さない**（このskillはメール参照しないが念のため）
- **ローカルmemory・ローカルfile参照は使わない**。Cowork制約のため。詳細版が必要なときはPCに移って Claude Code から `/ohayou` を打ち直す
- **CLI版 `/ohayou` との関係**: 別物として並走。Cowork-mobile版は速報のみ、CLI版は統合まとめ救済・学習ログ蒸留等のメンテ機能込み
